A tiny Node program that writes the funniest one-line excuse a robot vacuum could give for missing a spot: it scanned the spot, classified it as load-bearing dirt, and left it in place — removing it would void the floor's warranty. The line is written to `/output/entry.txt`, exactly one line of 161 characters, in a deadpan machine voice with the punch at the end.

## Run it

```bash
node main.ts
```

This writes the one-line excuse to `/output/entry.txt`.
